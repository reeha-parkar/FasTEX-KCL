FasTEX FTIR Spectral Database

A reference collection of averaged, baseline-corrected ATR-FTIR spectra for natural and man-made textile fibres, developed by King's Forensics, King's College London.

Open the interactive database → The interactive site (spectrum viewer, Absorbance/Transmittance toggle, peak detection) runs as a separate live application -- this page is a static landing page only. See the note in this file's source if the link above looks out of date.

About this dataset

Every spectrum in the database is the baseline-corrected average of the replicate ATR-FTIR measurements recorded for one fibre subtype, acquired on a PerkinElmer Frontier FT-IR spectrometer with a single-reflection diamond ATR accessory (4000–550 cm⁻¹, 4 cm⁻¹ resolution). Fibres are organised Origin → Type → Subtype, following the classification scheme described in the dataset's data descriptor article and informed by ISO 2076.
